# Дашборд для производственного комбината: коммерческое предложение

Командный учебный проект по бизнес- и системному анализу: коммерческое предложение на создание единой системы аналитики для производственного комбината. Включает описание Epic, границы проекта и MVP по этапам, сроки и бюджет, оценку трудозатрат по ролям, обоснование цены, AS-IS и TO-BE, схему систем и источников данных.

> Проект учебный: комбинат, данные, сроки и стоимость условные.

## Задача

Отсутствие **единого источника правды** для принятия управленческих и стратегических решений: данные разбросаны по 1С УПП и нескольким Excel-файлам, вносятся вручную, не синхронизированы. Нужен дашборд с ключевыми бизнес-метриками и инструментами прогноза и планирования производства.

## Ключевые решения

- **Поэтапный MVP из 3 этапов:** финансы и прогноз → мониторинг показателей производства → планирование производства. Каждый этап даёт самостоятельный результат.
- **Единая витрина данных** на базе ETL из 1С УПП и Excel-файлов (закупки и отгрузки, главный технолог, технолог, коммерческий директор).
- **Система алертов по термодатчикам** вместо еженедельной проверки локального Excel.
- **Планирование производства на 3 месяца вперёд** на исторических данных, калькулятор сроков нового заказа и плановый объём закупок сырья.
- **Оценка по ролям** (PM, BA, DE, BI) в часах с разбором, чем занимается каждая роль на каждой задаче.
