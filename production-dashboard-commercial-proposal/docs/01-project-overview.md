# 01. Описание проекта (Epic)

## Суть

| | |
|---|---|
| **Какую большую задачу бизнеса решаем** | Отсутствие **единого источника правды** для принятия управленческих и стратегических решений |
| **Что создаётся** | Дашборд с ключевыми бизнес-метриками и инструментами для прогноза и планирования производства |
| **Какая боль закрывается** | Управленческие ошибки из-за недостоверных данных; потеря прибыли из-за несвоевременного реагирования на изменения рынка; трата времени специалистов на ручную поддержку системы |
| **Целевая аудитория** | Собственник, финансовый директор, производственный директор, коммерческий директор, начальники цехов |

## Что станет лучше

| До | После |
|---|---|
| **Данные** фиксируются в разных источниках (1С УПП, локальные Excel, Excel с ограниченным доступом), неполные, несинхронизированные, неструктурированные | **Данные** собраны в один источник, нормализованы, синхронизированы, структурированы |
| Обнаружение проблем на термодатчиках раз в неделю через просмотр локального Excel | Оповещение о проблемах с температурным режимом сразу по факту (отправка данных раз в n минут) |
| Влияние человеческого фактора на расчёт бизнес-метрик (подгонка цифр, неполнота данных, нерегулярность обновления) | Автоматическая отправка данных производства после каждого завершённого этапа на оборудовании |
| Отсутствие информации о потерях на всех этапах производства и складе | *(то же)* |
| Отсутствие ежедневных данных по загрузке оборудования | *(то же)* |
| Отсутствие структуры и синхронизации в источниках данных | Синхронизированные и нормализованные источники данных |
| Невозможность планирования производства на срок более недели | Возможность планирования на 3 месяца вперёд на достоверных исторических данных |
| Неизвестность влияния изменения рецептур на прибыль бизнеса | Возможность проверки выгоды от изменения рецептур |
| Отсутствие понимания прибыльности определённых категорий товаров | Статистика прибыли в разрезе линейки товаров |

## Сценарии использования

- **Собственник и финансовый директор:** просмотр текущих бизнес-показателей и их прогноза.
- **Производственный директор:** ежедневный мониторинг загруженности оборудования, буфера узких горлышек, оповещений о проблемах с оборудованием, просмотр списка задач цехов.
- **Коммерческий отдел:** получение информации по объёмам закупок сырья, планирование сроков выполнения заказов и текущим возможностям комбината.

## Что НЕ делаем

Анализ клиентской базы и ретеншн.

## Бизнес-требования и метрики KPI

- **Проток** (Throughput) увеличивается (или, достигнув максимума, не снижается).
- Размер **товарно-материальных ценностей** снижается.
- **Операционные затраты** снижаются.

## Ожидаемые ресурсы

- Excel-файл технолога доступен для оцифровки.
- Доступ к данным 1С УПП не требует согласования.

## Технические ограничения

- Расхождение в данных исторических источников и невозможность установления соответствий (1С, Excel-файлы).
- Неструктурированный учёт данных в источниках (Excel закупок).
- Большой размер накопленных исторических данных.
